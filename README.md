# site-fuel-food-truck-amman

Concept website for **FUEL Food Truck**, a burger truck in Abdoun, Amman. It follows the look and motion of [cravburgers.shop](https://www.cravburgers.shop/) with our own code, words and art.

- **Preview:** https://labsuncut.github.io/site-fuel-food-truck-amman/ (once GitHub Pages is on)
- **Intake and facts:** https://github.com/labsuncut/ops/issues/3
- **What matches CRAV and what is guessed:** [docs/REFERENCE_AUDIT.md](docs/REFERENCE_AUDIT.md)

## What's in here

| File | What it is |
| --- | --- |
| `business.json` | Every fact about FUEL |
| `index.html` | The one-page site |
| `assets/js/content.js` | All the words, in English and Arabic, plus the opening hours |
| `assets/js/site.js` | All the animation (GSAP, ScrollTrigger, SplitText, MotionPath, Lenis) |
| `assets/js/vendor/` | Those animation libraries, saved here so the site needs no outside scripts |
| `assets/css/site.css` | All the styling. Colours are at the top |
| `assets/img/` | Favicon. FUEL's photos go here |
